Text embedding turns text into a vector of numbers that captures its
meaning. Texts about the same thing get similar vectors, which makes the
vectors useful for semantic search, text classification, clustering and
finding duplicates.

`createTextEmbedder` runs one of two models:

- [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2),
  the default: English, vectors of 384 numbers, a 45 MB download.
- [EmbeddingGemma 2](https://huggingface.co/google/embeddinggemma-2): 100+
  languages and code, texts up to 2048 tokens, vectors of 768 numbers that
  can be cut to 512, 256 or 128, a 574 MB download.

## Quick start

```ts twoslash
import { createTextEmbedder, models, similarity } from 'runntime/zoo';

// 1. Load the model once. The weights download from the Hugging Face Hub.
const embedder = await createTextEmbedder(models.textEmbedding.ALL_MINILM_L6_V2.DEFAULT);

// 2. Turn text into vectors.
const query = await embedder.embed('how do I reset my password');
const answers = await embedder.embedBatch([
  'Click "Forgot password" on the login page.',
  'Our office is open from 9 to 5.',
]);

// 3. Compare them.
similarity(query, answers[0]!); // 0.68, related
similarity(query, answers[1]!); // 0.05, unrelated

// 4. Free the GPU memory when done.
embedder.dispose();
```

The engine must be set up first, see [Getting started](/zoo/getting-started/).

## EmbeddingGemma 2

EmbeddingGemma 2 was trained with an instruction in front of each text, so
tell it what the text is for. A search embeds its queries with
`task: 'query'` and the texts it searches with `task: 'document'`.

```ts twoslash
import { createTextEmbedder, models, similarity } from 'runntime/zoo';

// 1. Load the model once.
const embedder = await createTextEmbedder(models.textEmbedding.EMBEDDINGGEMMA_2.DEFAULT);

// 2. Embed the query and the documents, each with its task.
const query = await embedder.embed('Which planet is known as the Red Planet?', { task: 'query' });
const docs = await embedder.embedBatch(
  [
    'Mars, known for its reddish appearance, is often referred to as the Red Planet.',
    "Venus is often called Earth's twin because of its similar size.",
    'Marte es conocido como el planeta rojo.',
  ],
  { task: 'document' },
);

// 3. Compare them. Other languages land in the same space.
similarity(query, docs[0]!); // 0.85
similarity(query, docs[1]!); // 0.68
similarity(query, docs[2]!); // 0.83, Spanish for the first one

embedder.dispose();
```

The tasks are `query`, `document`, `questionAnswering`, `factChecking`,
`classification`, `clustering`, `similarity` and `codeRetrieval`. Use the
same task for every text you compare, except the query and document pair
of a search.

## Methods

```ts
function createTextEmbedder(
  model?: TextEmbedderModel,
  options?: LoadOptions,
): Promise<TextEmbedder>;

interface TextEmbedder {
  readonly dim: number;
  embed(text: string, options?: EmbedOptions): Promise<Float32Array>;
  embedBatch(texts: readonly string[], options?: EmbedOptions): Promise<Float32Array[]>;
  dispose(): void;
}

interface EmbedOptions {
  readonly task?: EmbeddingTask; // EmbeddingGemma 2 only
}
```

- `embed(text)` turns one text into one vector of `dim` numbers.
- `embedBatch(texts)` does many texts in one go. Much faster than calling
  `embed()` in a loop. One vector per text, in the same order.
- `task` puts the task's instruction in front of every text, see
  [EmbeddingGemma 2](#embeddinggemma-2). MiniLM takes no task.
- `dim` is the length of every vector: 384 for MiniLM, 768 for
  EmbeddingGemma 2 unless `dims` asks for fewer.
- `dispose()` frees the GPU memory.

### Helpers

```ts
function similarity(a: Float32Array, b: Float32Array): number;
```

- `similarity(a, b)` is the cosine similarity of two vectors from the
  embedder, a number from -1 to 1. 1 means the same meaning, near 0
  unrelated.

## Options

The first argument is the model config, a plain object with the fields
below. `models` holds ready-made ones for each model: `DEFAULT`, the f16
weights run in f16 where the device has `shader-f16` and in f32 elsewhere;
`F16`, the same file with f16 forced; `F32`, the f32 weights run in f32.
Pass one as is, copy it with a field changed, or point at your own files.

```ts
interface TextEmbedderModel {
  readonly arch?: 'minilm' | 'embeddinggemma-2';
  readonly modelPath?: ModelPath;
  readonly tokenizerPath?: string;
  readonly dtype?: 'f32' | 'f16';
  readonly maxTokens?: number; // default 256 for MiniLM, 2048 for EmbeddingGemma 2
  readonly dims?: number; // EmbeddingGemma 2: 768, 512, 256 or 128
}

type ModelPath = string | RangeSource; // a URL, or bytes you already have
```

Examples:

```ts twoslash
import { createTextEmbedder, models } from 'runntime/zoo';

// Full precision: twice the download, results move by about 1e-3.
await createTextEmbedder(models.textEmbedding.ALL_MINILM_L6_V2.F32);

// The same model, shorter texts.
await createTextEmbedder({ ...models.textEmbedding.ALL_MINILM_L6_V2.DEFAULT, maxTokens: 128 });

// EmbeddingGemma 2 with vectors of 256 numbers, a third of the storage.
await createTextEmbedder({ ...models.textEmbedding.EMBEDDINGGEMMA_2.DEFAULT, dims: 256 });

// Your own copy of the files.
await createTextEmbedder({
  modelPath: '/models/minilm/model.safetensors',
  tokenizerPath: '/models/minilm/tokenizer.json',
});
```

- **arch** - `'minilm'` (default) or `'embeddinggemma-2'`. Picks the model
  the weights belong to. The ready-made configs set it.
- **modelPath** - the weights, a `model.safetensors` file. The original file
  from the Hub works as is, in f16 or f32, and for EmbeddingGemma 2 Google's
  bf16 file too.
- **tokenizerPath** - the `tokenizer.json` file next to it.
- **dtype** - `'f16'` or `'f32'`. `f16` runs the model in half precision,
  half the GPU memory, and needs a device with `shader-f16`. Default: `f16`
  where the device has it, `f32` elsewhere. Either loads any weight file.
- **maxTokens** - longest text in tokens: 256 by default for MiniLM, 2048
  for EmbeddingGemma 2, the most it runs here. Longer text is cut.
- **dims** - length of the returned vectors. EmbeddingGemma 2 takes 768
  (default), 512, 256 or 128: a shorter vector stores in less space and
  compares faster, at a small cost in quality. MiniLM's are always 384.

Every field is optional. A missing one comes from the model's `DEFAULT`,
`models.textEmbedding.ALL_MINILM_L6_V2.DEFAULT` when `arch` is not set.

## Loading options

The second argument controls the download. Every field is optional.

```ts
interface LoadOptions {
  cache?: WeightCache;
  cacheId?: string;
  onProgress?: (name: string, doneBytes: number, totalBytes: number) => void;
  onBytes?: (chunkBytes: number) => void;
  signal?: AbortSignal;
}
```

Example:

```ts twoslash
import { createOpfsCache, createTextEmbedder, models } from 'runntime/zoo';

const embedder = await createTextEmbedder(models.textEmbedding.ALL_MINILM_L6_V2.DEFAULT, {
  cache: await createOpfsCache('my-app'),
  onProgress: (name, done, total) => console.log(`${Math.round((100 * done) / total)}%`),
});
```

- **cache** - keeps the downloaded weights and tokenizer in the browser, so
  the next visit loads them without the network. `createOpfsCache(name)` is
  the built-in one.
- **onProgress** - called while the weights upload to the GPU, with the
  tensor name, bytes done and bytes total. Use it for a progress bar.
- **signal** - an `AbortSignal`. Abort it to stop the load between steps.
  A step already running, like the download or the GPU upload, finishes
  first.
