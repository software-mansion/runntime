Object detection finds bounding boxes for objects present in an image. You pass in the pixels and
get back a list: what each object is, how sure the model is, and where it
sits in the image.

`createObjectDetector` runs
[YOLO26](https://docs.ultralytics.com/models/yolo26/) by Ultralytics.

## Quick start

```ts twoslash
declare const canvas: HTMLCanvasElement;
// ---cut---
import { createObjectDetector, imageBufferFromImageData, models } from 'runntime/zoo';

// 1. Load the model once. The weights download from the Hugging Face Hub.
const detector = await createObjectDetector(models.objectDetection.YOLO26.DEFAULT);

// 2. Get the pixels of an image, here from a canvas the picture is drawn on.
const ctx = canvas.getContext('2d')!;
const image = imageBufferFromImageData(ctx.getImageData(0, 0, canvas.width, canvas.height));

// 3. Find the objects.
const objects = await detector.detectObjects(image);

// 4. Use them: one entry per object, best first.
for (const { label, confidence, box } of objects) {
  console.log(label, confidence, box);
}
// bus 0.93 { format: 'xyxy', xmin: 6, ymin: 228, xmax: 807, ymax: 749 }
// person 0.92 { format: 'xyxy', xmin: 47, ymin: 399, xmax: 237, ymax: 902 }
// ...

// 5. Free the GPU memory when done.
detector.dispose();
```

The example reads one picture off a canvas. A video or a camera works the
same way: draw each frame on the canvas and call `detectObjects` again, the
detector is loaded once.

The engine must be set up first, see [Getting started](/zoo/getting-started/).
The model runs in half precision, so the device needs `shader-f16`.

## Results

`detectObjects` returns a list with one entry per object found, best first.
Nothing found gives an empty list. Each entry is:

```ts
interface ObjectDetection {
  label: string; // what it is: 'person', 'bus', ... one of the 80 COCO classes
  classId: number; // the same as a number, index into detector.labels
  confidence: number; // how sure the model is, 0 to 1
  box: { format: 'xyxy'; xmin: number; ymin: number; xmax: number; ymax: number };
}
```

`box` is the top-left corner (`xmin`, `ymin`) and the bottom-right corner
(`xmax`, `ymax`) of the object, in pixels of the image you passed in.

## Methods

```ts
function createObjectDetector(
  model?: ObjectDetectorModel,
  options?: LoadOptions,
): Promise<ObjectDetector>;

interface ObjectDetector {
  readonly labels: readonly string[];
  readonly inputSize: number;
  readonly schemas: {
    readonly input: Yolo26Input;
    readonly output: (maxDetections: number) => ObjectDetectionList;
  };
  detectObjects(image: ImageBuffer, options?: DetectObjectsOptions): Promise<ObjectDetection[]>;
  encodeDetectObjects(options: EncodeDetectObjectsOptions): void;
  dispose(): void;
}

interface DetectObjectsOptions {
  readonly confidenceThreshold?: number; // default 0.3
  readonly maxDetections?: number; // default 300
}
```

- `detectObjects(image, options?)` returns the objects in the image, best
  first. `image` is an `ImageBuffer` of any size. Build one with
  `imageBufferFromImageData(imageData)` from a canvas, or
  `imageBuffer(bytes, width, height, format?)` from raw `rgba`, `rgb`,
  `bgra`, `bgr` or `gray` bytes.
  `confidenceThreshold` drops objects scored below it,
  `maxDetections` caps how many come back.
- `encodeDetectObjects(options)` reads an image already on the GPU and
  writes the objects to a GPU buffer, see
  [GPU in, GPU out](#gpu-in-gpu-out).
- `labels` are the class names, by class index. COCO's 80 for a standard
  checkpoint, `class 0`, `class 1`, ... for a custom one.
- `inputSize` is the model input width and height, 640 by default.
- `schemas` are the TypeGPU layouts of the model input and of the list
  `encodeDetectObjects` writes, for buffers passed to it.
- `dispose()` frees the GPU memory.

YOLO26 picks one box per object on its own, so there is no IoU threshold.

## GPU in, GPU out

When the image is already on the GPU, a video frame or the output of your
own shader, `encodeDetectObjects` skips the CPU: no pixels are read back, and the
objects are picked and decoded on the GPU, straight into a buffer you own,
for your next pass to draw or read.

```ts twoslash
declare const video: HTMLVideoElement;
// ---cut---
import { createObjectDetector, initRunntime, models } from 'runntime/zoo';
import tgpu from 'typegpu';

// 1. Set up the engine and load the model once.
const root = await tgpu.init({ device: { optionalFeatures: ['subgroups', 'shader-f16'] } });
initRunntime(root);
const detector = await createObjectDetector(models.objectDetection.YOLO26.DEFAULT);

// 2. A buffer for up to 100 objects, typed by the detector's schema.
const objects = root.createBuffer(detector.schemas.output(100)).$usage('storage');

// 3. Each frame: video in, the list out, then your own passes in the same encoder.
const encoder = root['~unstable'].createCommandEncoder();
detector.encodeDetectObjects({
  source: root.device.importExternalTexture({ source: video }),
  target: objects,
  confidenceThreshold: 0.5,
  encoder,
});
// ...record your own passes that read `objects` here...
encoder.submit();
```

**Source** - one of:

- a texture: a `GPUTexture`, a TypeGPU texture with `sampled` usage, or a
  `GPUExternalTexture` from a video. It is fitted like an `ImageBuffer`,
  with the detector's `resizeMode`, and each value 0-1 counts as a byte
  0-255. Formats: `rgba8unorm`, `bgra8unorm`, `rgb10a2unorm`,
  `rgba16float`, `rgba32float`. sRGB formats are rejected: the GPU would
  turn their values linear, which the model was not trained on.
- a buffer holding the model input as is: 3×640×640 f32 at the default `inputSize`, normalized RGB, one
  plane per channel. A raw `GPUBuffer` needs `COPY_SRC` usage.

**Target** - a buffer with `STORAGE` usage, laid out as
`schemas.output(maxDetections)`:

```wgsl
struct Box { xmin: f32, ymin: f32, xmax: f32, ymax: f32 }
struct ObjectDetection { box: Box, confidence: f32, classId: u32 }
struct ObjectDetectionList { count: u32, detections: array<ObjectDetection, maxDetections> }
```

The first `count` entries are the objects `detectObjects` would return, best
first. `box` is in pixels of the source image, cut at its edge; for a buffer source, of the model input. `confidence` is 0 to 1. `classId` indexes `labels`. Entries past `count` keep old values. Every field is 4 bytes
with no padding, so in a raw `GPUBuffer` entry `i` starts at byte
`4 + 24 * i`.

`confidenceThreshold` drops objects scored below it, 0.3 by default.
`maxDetections` caps how many are written, by default as many as the target
holds.

**encoder** - optional. Pass a `GPUCommandEncoder` or a TypeGPU command
encoder to record the detection together with your own passes into one command
buffer. You then finish and submit it yourself, before `dispose()`. Without
it, the call submits its own before it returns, and does not wait for the
GPU. Work you submit after it sees the result.

Every resource must come from the device passed to `initRunntime()`. A
wrong format, usage or size, or an option out of range, throws
`INVALID_ARGUMENT`.

## Options

The first argument is the model config, a plain object with the fields
below. `models.objectDetection.YOLO26` holds ready-made ones: `N` (5 MB,
the `DEFAULT`), `S` (18 MB) and `M` (39 MB, more accurate, slower). Pass one as is, copy
it with a field changed, or point at your own safetensors export of an
Ultralytics YOLO26 detect checkpoint.

```ts
interface ObjectDetectorModel {
  readonly modelPath?: ModelPath;
  readonly variant?: 'n' | 's' | 'm' | 'l' | 'x';
  readonly inputSize?: number; // default 640
  readonly resizeMode?: 'letterbox' | 'stretch' | 'crop'; // default 'letterbox'
}

type ModelPath = string | RangeSource; // a URL, or bytes you already have
```

Examples:

```ts twoslash
import { createObjectDetector, models } from 'runntime/zoo';

// The medium size.
await createObjectDetector(models.objectDetection.YOLO26.M);

// Faster, for a camera loop.
await createObjectDetector({
  ...models.objectDetection.YOLO26.DEFAULT,
  inputSize: 512,
  resizeMode: 'crop',
});

// Your own copy of the file.
await createObjectDetector({ modelPath: '/models/yolo26n/model.safetensors' });
```

- **modelPath** - the weights, a `model.safetensors` file. Default:
  `models.objectDetection.YOLO26.DEFAULT.modelPath`.
- **variant** - the model size, `n`, `s`, `m`, `l` or `x`. Read from the
  weights by default.
- **inputSize** - model input width and height, a multiple of 32. Default 640. Smaller is faster and misses more small objects.
- **resizeMode** - how the image fits the model input. `letterbox`
  (default) pads, `stretch` distorts, `crop` cuts the centered square.

## Loading options

The second argument controls the download. Every field is optional.

```ts
interface LoadOptions {
  cache?: WeightCache;
  cacheId?: string;
  onProgress?: (name: string, doneBytes: number, totalBytes: number) => void;
  onBytes?: (chunkBytes: number) => void;
  signal?: AbortSignal;
}
```

Example:

```ts twoslash
import { createObjectDetector, createOpfsCache, models } from 'runntime/zoo';

const detector = await createObjectDetector(models.objectDetection.YOLO26.DEFAULT, {
  cache: await createOpfsCache('my-app'),
  onProgress: (name, done, total) => console.log(`${Math.round((100 * done) / total)}%`),
});
```

- **cache** - keeps the downloaded weights in the browser, so the next
  visit loads them without the network. `createOpfsCache(name)` is the
  built-in one.
- **onProgress** - called while the weights upload to the GPU, with the
  tensor name, bytes done and bytes total. Use it for a progress bar.
- **signal** - an `AbortSignal`. Abort it to stop the load between steps.
  A step already running, like the download or the GPU upload, finishes
  first.

`modelPath` too.
