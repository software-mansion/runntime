title: 'runntime/core'
description: The engine — PyTorch-style nn modules, eager execution, and weight loading for the web.
---

ruNNtime core is a TypeGPU-powered, programmable inference engine. Define a model as a
tree of `nn.Module`s with an imperative `forward()`, then load weights from a
safetensors checkpoint with `loadStateDict`.
