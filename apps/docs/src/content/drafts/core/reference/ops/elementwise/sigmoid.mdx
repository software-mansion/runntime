## Signature

```ts
sigmoid(x: Value): Value
```

Method form:

```ts
x.sigmoid();
```

Applies the logistic function, elementwise:

```
out[i] = 1 / (1 + e^(-x[i]))
```

Returns a pending Value with the same shape and dtype as `x`: nothing
runs until evaluation.

## Parameters

- **x** (`Value`) — the input Value.

## Constraints

- packedF16 / quantW Values are not accepted, they are packed weight
  storage that only `matmul` can read.
