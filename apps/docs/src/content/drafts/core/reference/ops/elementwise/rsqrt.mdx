## Signature

```ts
rsqrt(x: Value): Value
```

Method form:

```ts
x.rsqrt()
```
Computes the reciprocal square root, elementwise:

```
out[i] = 1 / sqrt(x[i])
```

Returns a pending Value with the same shape and dtype as `x`: nothing
runs until evaluation.

## Parameters

- **x** (`Value`) — the input Value.

## Example

<Tabs syncKey="framework">
<TabItem label="ruNNtime">
```ts
const invStd = variance.rsqrt();   // normalization building block
```
</TabItem>
<TabItem label="PyTorch">
```python
inv_std = variance.rsqrt()
```
</TabItem>
</Tabs>

For full normalization layers, prefer the fused
[`rmsNorm`](/core/reference/ops/functional/rms-norm/) /
[`layerNorm`](/core/reference/ops/reduce/layer-norm/) instead of composing
them from `mean`/`rsqrt`/`mul`.

## Constraints

- packedF16 / quantW Values are not accepted, they are packed weight
  storage that only `matmul` can read.
