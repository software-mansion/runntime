## Signature

```ts
swigluChunk(x: Value): Value
```

Function-only:

```ts
swigluChunk(x);
```

Applies the SwiGLU activation to one concatenated Value,
`[T,2F] → [T,F]`:

```
hidden = x[:, 0:F]     // first F columns
gate   = x[:, F:2F]    // last F columns
out    = silu(gate) · hidden
```

The column order (hidden first, gate second) matches Hugging Face
models. Weights trained with the opposite order produce wrong results,
not an error. The whole formula runs as one fused kernel: a single GPU
pass instead of separate ops, so it is faster than composing it from
`slice`/`silu`/`mul`. Returns a pending Value of shape `[T,F]`:
nothing runs until evaluation.

## Parameters

- **x** (`Value`) — hidden and gate halves concatenated along columns,
  `[T,2F]`.

For the clamped variant that takes the two halves as separate Values,
see [`swiglu`](/core/reference/ops/elementwise/swiglu/).

## Constraints

- 2D f32 input with an even number of columns.
