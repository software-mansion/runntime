`Value` is the array type of `runntime/core` — the analogue of `torch.Tensor`.
Every op takes and returns Values.

A Value is one node of a lazy computation graph, always in one of two
states (check with `value.state`):

- **materialized** — backed by a real GPU buffer holding the numbers:
  uploaded data (weights, model input), or an op result after evaluation.
- **pending** — no data yet. The Value holds a recipe instead: which op
  produces it, and from which input Values.

Calling an op never runs anything on the GPU — it only creates a new
pending Value linked to its inputs. Shapes and dtypes are validated
immediately, so mistakes throw at the call site. The GPU runs when you
read a result:

```ts
const x = tensor(root, data, [2, 64]); // upload — materialized
const h = x.matmul(w, { bias }); // pending — nothing ran yet
const y = h.tanh(); // still pending
const out = await toArray(y, exec); // whole chain runs, one GPU submit
```

`toArray` (or `evalValues`) walks the pending nodes behind the requested
Value, runs them in one batched submit, and flips them to materialized.
